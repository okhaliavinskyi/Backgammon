## Уточнения реализации относительно буквальных snippets v3

1. `.pdiff` остаётся sibling `.pmeta`, оба внутри одной строки `.strip-stats`.
   Полоса резервирует минимум 60px. Две раздельные строки давали лишнюю высоту,
   сдвигали доску при смене лидера и обрезали кнопку удвоения. Теперь кнопка
   помещается, размер доски сохраняется. В STATES_ONLY добавлена проверка этого
   состояния, а PREVIEW сравнивает доску до ходов и после Undo/settings.
2. Дополнительные claim/double вынесены в отдельную строку ActionBar. С компактными
   полосами она помещается в 360×780; основные действия сохраняются.
3. Палитра реакций — 4×2, закрывается выбором, Escape или кликом снаружи.
   Однострочный набор из 8 кнопок не помещался на телефоне.
4. Имя из 20 букв W теперь обрезается многоточием внутри чипа, поле редактирования
   ограничено шириной колонки. Добавлены снимки и автоматическая проверка.
5. E2e получил IMPL_SCREEN_DIR для временных снимков; исторические tracked PNG
   не перезаписываются. Новая матрица `e2e/redesign.e2e.cjs` хранит финальные
   `redesign-*`, проверяет resume, фильтр, clipboard, visibility pill, menu/resign,
   password/not-found, simulated motion permission и геометрию живого online-chat.
6. PREVIEW baseline измерен заново: top=140.390625px (раньше 66.1875),
   width=344px, height=431.953125px, нижний зазор=12px. Изменён только baseline
   верхнего положения: полоса соперника теперь над доской. Ширина/высота прежние.

CLI/ChatGPT account; MCP initialization также получил HTTP 403. Конфигурация
аккаунта/модели не менялась. Лог: `/tmp/nardy-review-run.log`. Ни этот запуск,
ни самоаудит ниже не считаются независимым green review. Это оставшееся ограничение
приёмки; два раунда ревью ПЛАНА завершены ранее и не повторялись.

Ничего не пушилось, не сливалось в main, не деплоилось; production-проверки нет.

   в узкой полосе могут показываться с многоточием; title имени сохраняется.

   Текст «Выйти» не обещает закрыть комнату на сервере.

   отдельной задачи нарушила бы scope и могла бы затронуть планшет.
