# Геймификация: состояние реализации

16 ноября 2026. V1-A включена в `main` (`75b1912`). V1-B реализуется отдельно в `codex/ranked-v1b`, без публикации этой ветки.

## Решение о регистрации

[Оценка и будущий сценарий аккаунта](GAMIFICATION-IDENTITY.md): регистрация не нужна для V1-A. Гостевой профиль создаётся автоматически; email, пароль и подтверждение почты не добавляются. Будущий аккаунт нужен для восстановления и нескольких устройств, но не для входа в комнату.

## Реализовано

- Гостевой серверный профиль в отдельном SQLite Durable Object, доступ через HttpOnly cookie.
- Вход по ссылке с единственным запросом имени, если оно ещё не сохранено.
- Опыт, уровни, монеты, дневной и стартовый бонусы, четыре предмета уровней.
- Магазин из 10 товаров, примерка, подтверждение покупки, проверка баланса и владения, применение и сброс оформления.
- Шесть значков, статистика матчей отдельно от партий, личный счёт в итогах.
- Бесплатные существующие темы, новые Янтарь и Сланец, два варианта костей и косметика профиля.
- Скрытие прогресса в игре; нулевой баланс не ограничивает игровые режимы.
- Серверное начисление, атомарные покупки, защита от повторов, лимит монет одной пары, ранние сдачи без наград.
- Сохранённая в комнате очередь начислений с повтором через alarm при ошибках сервиса профилей.
- Ограничение одной активной награждаемой комнаты на профиль; переход из отключённой комнаты возможен без ожидания истечения её срока. Ограничение одного игрока не отбирает награды у другого.
- Проверка типов, браузерные проверки с двумя профилями, интеграция в CI. Playwright добавлен в devDependencies; браузер устанавливается отдельным шагом CI.

V1-B (Elo, ранги и рейтинговый подбор) реализована отдельно; формат, API и проверки описаны в [RANKED-V1B.md](RANKED-V1B.md). Обязательного аккаунта нет. Локальный ИИ и hot-seat серверную валюту не создают.

Косметика доски и костей применяется к собственному отображению сразу. Аватар/рамка передаются сопернику при входе или восстановлении подключения; живое обновление из другой вкладки без переподключения не предусмотрено.

## Проверки

- Проверка: 25 тестов движка и 15 серверных/браузерных тестов прошли; расширенный сценарий параллельных комнат отдельно перепроверен после последнего изменения.
- `npm run typecheck`
- `npm test` — существующие 25 тестов движка.
- `npm run build`
- `NARDY_URL=http://127.0.0.1:18923 npm run test:integration -w @nardy/worker` — проверки против локального Worker; запуск последовательно, чтобы не смешивать лимиты между файлами.
- `npx wrangler deploy --dry-run --config worker/wrangler.toml --outdir /tmp/nardy-gamification-dry-run` — упаковка без публикации.
- Браузер: два независимых профиля, полный матч, ранняя сдача, 11 зачётных партий одной пары, повторная покупка, недостаток монет, запрет чужого профиля, переподключение без повторного начисления, мобильная примерка темы без горизонтального переполнения, запрет параллельного фарма без лишения наград второго участника, переход из отключённой комнаты без 35-минутной блокировки.

Локальный сервер для проверки использует отдельный порт и хранилище:

```sh
npm run dev -w @nardy/worker -- --port 18923 --inspector-port 19237 --persist-to /tmp/nardy-gamification-v1-local
```

Перед первым запуском браузерных проверок: `npx playwright install chromium`.

## Границы проверки

Повторная доставка результата проверена через переподключение. Отказ удалённого сервиса профилей и перезапуск Worker во время доставки outbox отдельно не имитировались. Тестов на массовый подбор нет, поскольку V1-B не включена. Числа экономики остаются гипотезой до наблюдения реальных партий.

Профиль, связывающий историю нескольких комнат, требует согласованных сведений о данных и удаления; существующая параллельная работа над приватностью сохраняется. Деплой и merge не выполнялись.
