# V1-B: гостевой рейтинг и подбор

16 ноября 2026. Реализация отдельного рейтингового режима поверх V1-A.

## Вход и правила

Регистрация, email, платёж или положительный баланс не требуются. Используется существующий гостевой профиль браузера. Имя спрашивается только если его ещё нет. Обычные комнаты и приглашения по ссылке остаются доступными и не меняют Elo.

Матч до 3 очков, задержка на ход 15 секунд, затем общий банк 5 минут каждому. Короткие: кубик включён, правило Кроуфорда. Длинные: без кубика. Рейтинговая сдача означает поражение во всём матче; в обычной комнате сохраняются прежние правила сдачи партии.

Длинные и короткие имеют независимые Elo: старт 1 000. Первые десять матчей — калибровка с K=64, затем K=32. Изменение считается от рейтингов обоих игроков до матча; округление до ближайшего целого с половинами от нуля. При разных K сумма изменений не обязана равняться нулю.

Ранги: Бронза <900, Серебро 900–1099, Золото 1100–1299, Платина 1300–1499, Алмаз 1500–1699, Мастер ≥1700. До десяти матчей показывается калибровка, лучший ранг сохраняется только после её завершения. Монет за ранг нет, сезонов и штрафа за неактивность нет.

## Подбор

- Отдельный Durable Object на вариант нард; атомарная резервация в профиле запрещает одновременно искать/играть в двух рейтинговых пулах.
- Сначала разница Elo до 100; каждые 15 секунд ожидания диапазон растёт на 100. После двух минут допустима любая разница.
- Для пары применяется больший диапазон ожидания; среди подходящих предпочитается близкий Elo, при равенстве — более ранний вход.
- Нет жёсткого запрета повторного соперника. Нет подмены человека ботом.
- Браузер обновляет поиск раз в 3 секунды. Запись без heartbeat удаляется после 30 секунд; временная резервация очереди в профиле истекает после 45 секунд.
- Отмена до фиксации пары удаляет очередь. После фиксации пары API возвращает назначенную комнату: отмена/повторный POST не создают вторую комнату.
- Закрытие экрана отправляет отмену через keepalive; при потере сети запись истечёт по heartbeat.
- Долгое ожидание не запускает другой режим автоматически. Пользователь может отменить поиск и выбрать игру с другом.

## Рейтинговая комната

Сервер резервирует оба места за профилями участников. Даже знание кода комнаты или чужого комнатного токена не даёт третьему профилю занять рейтинговое место: нужен исходный секретный cookie профиля. Идентификаторы профилей и секреты не отправляются сопернику.

Матч начинается только после подключения обоих игроков. Если оба не подключились за минуту после создания комнаты, он отменяется без Elo, резервации освобождаются. Повторное открытие восстанавливает своё место без повторного имени.

После старта при отключении действует 120 секунд на возврат; банк продолжает идти и может закончиться раньше. По истечении окна сервер завершает матч поражением отсутствующего без необходимости нажатия «заявить победу». Если отключились оба, первым проигрывает тот, чей срок восстановления истёк раньше; одинаковые отметки разрешаются порядком мест. Это правило для клиентских отключений, не административная отмена из-за доказанной серверной аварии.

Реванша с фиксированным соперником внутри рейтинговой комнаты нет. После результата доступен новый подбор; та же пара может встретиться снова через очередь.

## Сохранность и доставка

Очередь, фиксация пары, зарезервированная комната, исходные рейтинги и результаты сохраняются до внешних RPC. Незавершённое создание пары повторяется из сохранённой записи, с проверкой идентичности участников. Коллизия с обычной комнатой не изменяет её настройки: выбирается другой код.

Elo меняется один раз за матч по серверному результату, независимо от права на XP/монеты, числа ходов и ранней сдачи. XP остаётся наградой за отдельные партии по V1-A. Итог Elo сохраняется в журнале с ключом комнаты; повтор доставки или восстановление подключения его не дублирует.

Для двух профилей нет общей распределённой транзакции: результаты доставляются отдельно и идемпотентно. Необработанная доставка остаётся в комнате и повторяется alarm. До сохранения собственного результата профиль не может начать следующий рейтинговый матч. Интерфейс показывает «Сохраняем рейтинг…» до завершения обеих доставок. Комната с недоставленным результатом не удаляется по обычному сроку неактивности.

Перезапуск/hibernation сами по себе не сбрасывают матч и резервации. Внешние RPC не вызываются внутри SQL-транзакций. Клиент не может передать Elo, результат, коэффициент или настройки рейтинговой комнаты.

## API

`POST /api/ranked/{long|short}` с `{name}` — поиск/возврат существующего назначения.
`GET /api/ranked/{long|short}` — heartbeat/состояние.
`DELETE /api/ranked/{long|short}` — отмена ещё не зафиксированного поиска.

Все используют HttpOnly cookie V1-A, проверку origin, ограничение частоты; POST ограничен 256 байтами. Состояния: `idle`, `searching` с временем начала, `matched` с кодом комнаты, `busy` для поиска в другом варианте. Сбой подбора возвращает 503; обычная игра остаётся доступной.

Миграция `v3-ranked` добавляет `MatchmakingDO`; старые профили получают начальные рейтинги без потери опыта и инвентаря. Экспорт профиля включает рейтинги и историю их изменений, но не внутреннюю резервацию или секреты.

## Ограничения

Анонимность позволяет создавать новые профили и заново проходить калибровку. Elo оценивает результаты, а не качество решений; автоматического обнаружения внешних подсказок нет. Регистрация не навязывается ради решения этих задач.

Автоматическая компенсация доказанной инфраструктурной аварии с откатом уже подтверждённых Elo не реализована: обычные перезапуски используют сохранённое состояние, а подтверждённые результаты не сбрасываются по сообщению клиента. Нужен отдельный операторский процесс для редких массовых инцидентов.

Рейтинговые записи входят в существующий экспорт/удаление гостевого профиля. Записи активной очереди удаляются по heartbeat; история результата хранится в профиле по его политике неактивности.

## Проверки

Математика Elo/рангов/диапазона — unit-тесты. Браузерные интеграционные проверки: два гостя, смена варианта и отмена, запрет третьего участника и параллельных очередей, отсутствие Elo после отдельной партии, сдача всего матча, повторный вход без повторного Elo, десять калибровочных матчей, неизменность рейтинга в дружеской комнате, неявка до старта, полный UI-путь с вводом имени и мобильный экран.

Локально:

```sh
npm run build
npm run dev -w @nardy/worker -- --port 18925 --inspector-port 19239 --persist-to /tmp/nardy-ranked-v1b-local
NARDY_URL=http://127.0.0.1:18925 npm run test:integration -w @nardy/worker
```

Незавершённую серверную доставку после искусственного отказа профиля нужно проверять отдельно; тесты неявки до старта и отключения после старта используют настоящие минутный и 120-секундный сроки.

Итог проверки: 28 unit-тестов и 19 серверных/браузерных тестов прошли; полный интеграционный прогон занял около четырёх минут с реальными таймерами. Сборка, typecheck, Worker dry run и существующий screens gate прошли. Ветка основана на опубликованной V1-A `75b1912`; V1-B не публиковалась.
