# /pickup

Цель: не начать вторую работу поверх чужой недоделанной первой.

1. **Где я.** Вывод SessionStart уже назвал ветку, последний коммит и число
   незакоммиченного. Незакоммиченное чужое — не трогать: `git checkout --`,
   `git restore`, `git reset --hard`, `git stash`, `git add -A` запрещены,
   пока в дереве работает кто-то ещё.

2. **Что уже сделано.** Читать по порядку, каждый следующий уточняет предыдущий:
   - `git log --oneline -15` и `git branch -a` — что реально влилось;
   - `GATES.md` — какие ворота закрыты и чем доказаны;
   - `docs/` — спека и план текущей работы;
   - открытые PR (`gh pr list`).

3. **Оценка продолжения.** Написать в двух строках: что незакончено и что
   блокирует. Незаблокированный пункт есть — брать его.

4. **Выполнить в том же прогоне.** «Прочитал, вот что дальше» — половина работы.

5. Продолжать работу по модели веток из CLAUDE.md проекта. Для worktree-модели — новая ветка от свежего main.
