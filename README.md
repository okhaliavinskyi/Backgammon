# Нарды · Nardy

Длинные и короткие нарды в браузере: онлайн-комнаты с друзьями и игра против ИИ трёх уровней.
Работает на телефоне (PWA, бросок встряхиванием, вибрация) и на десктопе.

- **Онлайн:** комнаты с паролем или без, лобби открытых комнат, ссылка-приглашение, чат и эмодзи, переподключение после обрыва, таймер хода и банк времени.
- **Против ИИ:** Новичок / Любитель / Мастер (expectimax на 1 ход); считается в Web Worker, работает офлайн, партия сохраняется.
- **Правила:** полные классические правила обоих вариантов — голова, запрет блока из 6, бой и бар, кубик удвоения, правило Кроуфорда, марс, гаммон и бэкгаммон.
- **Графика и звук:** всё процедурное — SVG-доска в трёх темах, 3D-кости на CSS, звуки синтезируются Web Audio. Ни одного файла-картинки или аудио.

## Структура

| Путь | Что внутри |
|---|---|
| `packages/core` | Движок правил, генерация ходов, матч, ИИ, протокол — общий для клиента и сервера |
| `apps/web` | Клиент: React 19 + Vite, Zustand |
| `worker` | Cloudflare Worker + Durable Objects (`RoomDO`, `LobbyDO`) |
| `docs/` | [SPEC](docs/SPEC.md) · [PLAN](docs/PLAN.md) · [DEPLOY](docs/DEPLOY.md) · [REVIEW](docs/REVIEW.md) |
| `e2e/` | Браузерный e2e на Playwright |
| `.github/workflows/` | CI (`ci.yml`) и автодеплой в Cloudflare при push в `main` (`deploy.yml`) |

## Быстрый старт
```bash
npm ci
npm run build && npm run dev:worker   # → http://127.0.0.1:8787
```
Деплой описан в [docs/DEPLOY.md](docs/DEPLOY.md): после добавления двух секретов в GitHub всё выкатывается автоматически.
